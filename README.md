# PulseCRM — Complete CRM Sales Dashboard

Fresh React + Vite CRM training project.

## Included
- Sales dashboard with revenue/KPI cards
- Revenue trend and pipeline charts
- Lead CRUD: add, edit, view, delete
- Contact management
- Deal management
- Sales pipeline / Kanban
- Drag-and-drop deal stages
- Lead and deal stages
- Follow-up dates
- Activity timeline
- Notes
- Search, filters, sorting and pagination
- Form validation
- Confirmation modal
- Loading, error and empty states
- Toast notifications
- Responsive desktop/tablet/mobile layouts
- Reusable UI components
- Micro animations
- No backend required; mock data is held in React state

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```
